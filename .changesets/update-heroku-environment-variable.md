We updated our code to reflect Heroku's deprecation of environment variable
`HEROKU_SLUG_COMMIT` and replacing it with `HEROKU_BUILD_COMMIT`.

See Heroku's [deprecation
announcement](https://devcenter.heroku.com/changelog-items/2886) and [Heroku
Labs: Dyno Metadata](https://devcenter.heroku.com/articles/dyno-metadata) for
more information.
